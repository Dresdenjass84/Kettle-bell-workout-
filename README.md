# Kettlebell Timer

A timed kettlebell circuit app for one 10 kg bell. Pick a length, a focus and your work/rest timings, and it builds a varied workout with animated move demos, beeps and voice cues. It works offline once installed on Android.

**Live site:** https://jass-kettlebell-timer.netlify.app

See `CLAUDE.md` for how it works, the decisions behind it, deployment, and testing.
